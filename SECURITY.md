# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

**Do not create a public GitHub issue for security vulnerabilities.**

Please send a vulnerability report to:

**Email:** `solmosov.dev@gmail.com`

When reporting a vulnerability, please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected module and version
* Potential impact
* Any relevant logs, screenshots, or proof of concept

We will review the report and, when appropriate, work on a fix and release a security update.

## Responsible Disclosure

Please allow the maintainers reasonable time to investigate and address a reported vulnerability before publicly disclosing it.

Thank you for helping keep this project secure.
